# RESTORE FACTORY SETTINGS

[Settings](../settings.md)

Sets every setting on the page back to its factory value.

| | |
|---|---|
| **Values** | NO / YES |
| **Origin** | The arcade's own row |

This row works in two steps, as on the cabinet. Press `Right` to change it to **YES**; the page then shows PRESS ENTER. Press `Enter` to perform it. `Left` returns it to NO.

## Values restored

| Setting | Value |
|---|---|
| [EXTRA MAN EVERY](extra-man-every.md) | 25000 |
| [TURNS PER PLAYER](turns-per-player.md) | 3 |
| [DIFFICULTY OF PLAY](difficulty-of-play.md) | 5 |
| [ATTRACT MODE SOUND](attract-mode-sound.md) | OFF |
| [BOZO MODE](bozo-mode.md) | ON |
| [BRAINS CHASE MIKEY BUG](brains-chase-mikey-bug.md) | ON |
| [TANK SHELL BUG](tank-shell-bug.md) | ON |

## Not affected

The high score table, the control definitions and the game style chosen on the [main menu](../main-menu.md) are left as they are. To clear the scores use [HIGH SCORE TABLE RESET](high-score-table-reset.md).
