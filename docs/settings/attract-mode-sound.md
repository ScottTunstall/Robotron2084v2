# ATTRACT MODE SOUND

[Settings](../settings.md)

Chooses whether the attract sequence plays sound.

| | |
|---|---|
| **Values** | ON / OFF |
| **Factory value** | OFF |
| **Origin** | Port only. The arcade has no such row. |

The attract sequence includes the title screen, the story, the high score table and the demonstration game in which the machine plays itself. On the arcade these make their normal sounds.

This game normally runs on a computer someone is sitting at, so the attract sounds are off by default. Turning the setting ON restores them. Sound during a real game is not affected by this setting.
