# HIGH SCORE TABLE RESET

[Settings](../settings.md)

Clears the high score table.

| | |
|---|---|
| **Values** | NO / YES |
| **Origin** | The arcade's own row |

This row works in two steps, as on the cabinet. Press `Right` to change it to **YES**; the page then shows PRESS ENTER. Press `Enter` to perform it. `Left` returns it to NO.

The reset cannot be undone. No other setting is changed.
